Acceso

La sesión usa el secreto admin. Salir lo borra de este navegador.

Crear, editar, cobrar, bloquear y eliminar se guarda en el servidor de licencias.

De dónde sale cada número

Descargas: instaladores .exe de GitHub Releases, acumulados por versión. No hay fecha de cada descarga.

Equipos: un registro por máquina que abrió la app. No contamos cada apertura.

Cuentas: emails verificados. Una prueba de 7 días no es una cuenta.

Cobrado: solo pagos cargados en el historial. Lo anterior a ese registro no se reconstruye. Las fechas del informe usan hora de Argentina.

Nueva licencia

Vacío = empieza hoy. Ej.: dar clave hoy pero ciclo desde el 1/10 → vence ~1/11.

Editar licencia

Podés pasar de Gratis permanente a un plan pago en la misma clave. La app del cliente toma el cambio en el próximo refresh de licencia.

Al guardar con fecha, recalcula el vencimiento = inicio + 30 días. Dejá vacío para no cambiar la fecha de vencimiento actual.

Si completás ambas, gana «Vence el».
