Preguntas frecuentes

¿Puedo vender por docena?

Sí. Docena es una de las unidades del rubro panadería.

¿Se conecta a la balanza?

Lee la etiqueta con código de barras que imprime la balanza. No se conecta por cable.

¿Funciona sin internet?

Sí. WalQo se instala en la PC del local. Hace falta conexión para bajarlo y crear la cuenta; después las ventas se guardan en esa computadora aunque se corte internet.

¿Cuánto sale?
