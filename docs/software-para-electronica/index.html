Sistema para casas de electrónica y celulares

Cada modelo con su color y su capacidad, y el stock de cada uno.

Modelos con variantes

Cargás el modelo una vez y le sumás colores y capacidades. Cada variante tiene su stock, su código de barras y su código interno.

Accesorios y servicio

Fundas, cargadores y auriculares van como productos comunes, con código de barras y stock por unidad.

Caja y clientes

Cada venta queda registrada con el medio de pago. Si vendés en cuotas propias, la cuenta corriente del cliente muestra el saldo.

Preguntas frecuentes

¿Puedo separar el stock por color y capacidad?

Sí. Cada combinación de color y capacidad es una variante con su cantidad.

¿Funciona sin internet?

Sí. WalQo se instala en la PC del local. Hace falta conexión para bajarlo y crear la cuenta; después las ventas se guardan en esa computadora aunque se corte internet.

¿Lleva el IMEI de cada equipo?

WalQo guarda un código interno por variante. No registra un IMEI distinto por cada unidad vendida.

¿Cuánto sale?
