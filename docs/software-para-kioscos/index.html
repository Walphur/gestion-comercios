Para el ritmo de un kiosco

Un software para comercios de este tipo tiene que responder mientras atendés. No hace falta cargar un sistema de sucursales ni de depósito central. Cargás lo que vendés, ponés el precio y empezás.

Si el kiosco tiene más de una computadora, una puede compartir productos, precios y stock con la otra dentro del local.

Stock que acompaña la venta

Cada venta descuenta. Cuando algo está por acabarse, lo ves en el sistema de control de stock en vez de descubrirlo cuando el cliente ya lo pidió.

La licencia mensual sale $35.000 e incluye ventas, productos, stock, el catálogo y las actualizaciones. La permanente, de $12.000, es un pago único para una sola PC.

Preguntas frecuentes

¿Funciona con lector de código de barras?

Sí, con cualquier lector USB que funcione como teclado. Escaneás y el producto entra al ticket.

¿Avisa cuando algo está por vencer?

Sí. Cada producto puede llevar su fecha de vencimiento, y el inicio muestra los que vencen en los próximos 14 días.

¿Funciona sin internet?

Sí. Hace falta conexión para instalarlo y crear la cuenta. Después podés vender sin internet: las ventas quedan en la PC del kiosco.

¿Cuánto sale?

Podés probarlo gratis, con hasta 25 productos y 50 ventas por mes. WalQo Completo sale $35.000 por mes y la permanente $12.000, una sola vez.
