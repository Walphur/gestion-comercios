Preguntas frecuentes

¿Cuántas cajas puedo tener?

Pro sincroniza hasta tres PCs en la misma red del local.

¿Lee etiquetas de balanza?

Sí. Lee el código con PLU que imprime la balanza, por importe o por peso.

¿Funciona sin internet?

Sí. WalQo se instala en la PC del local. Hace falta conexión para bajarlo y crear la cuenta; después las ventas se guardan en esa computadora aunque se corte internet.

¿Cuánto sale?

Este rubro viene con Pro, que sale $60.000 por mes e incluye tres PCs, presupuestos, turnos, remitos y órdenes.
