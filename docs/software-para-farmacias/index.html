Lo que no hace

WalQo es el sistema del mostrador: ventas, stock, caja y clientes. No valida recetas ni liquida obras sociales con las prestadoras.

Preguntas frecuentes

¿Puedo cargar el mismo medicamento con dos vencimientos?

Sí. Cada lote tiene su fecha y su cantidad, y el stock total es la suma de las partidas.

¿Funciona sin internet?

Sí. WalQo se instala en la PC del local. Hace falta conexión para bajarlo y crear la cuenta; después las ventas se guardan en esa computadora aunque se corte internet.

¿Sirve para una droguería?

Sí, si vende por unidad, caja o pack con código de barras. El control por lote es el mismo.
